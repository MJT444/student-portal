This repo is to showcase git tool as a class assignment.

## Initial repo in your local:

git init -b main

## Add .gitignore

add .gitignore

## Stage the change:

git add .

## Check the staged files:

git status

## Commit the change with a meaningful message:

git commit -m "Your meaningful commit message"

## Add the remote repo:

git remote add origin https://github.com/

## Push the commit:

git push -u main

## Clone the repo

git clone github.com/repo-name

## Opening the file

You can open the dashboard.html in any browser. It contains link to other pages.
